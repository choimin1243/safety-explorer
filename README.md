# 송명 안전 탐험대

인천송명초 둘레 실제 동네(OpenStreetMap)를 3D로 걸으며 안전 미션 10개를 해결하는 초등 안전교육 게임입니다. 설치 없이 브라우저에서 실행됩니다.

- 🚦 등굣길 스쿨존 횡단보도 · 🚌 버스에서 내린 뒤 · 🛴 킥보드 · 🚗 지하주차장 출입구 · 🛝 놀이터
- 🙅 모르는 사람의 부탁 · 🔥 상가 화재 대피(소방차 출동) · 🌏 학교 지진 대피 · 🚧 공사장 · 🚑 응급 119(구급차 출동)
- 미션마다 대화 선택지 + 직접 행동 + 별점, 10개를 마치면 수료증

## 그림
사람·차·소품은 모두 sprite-stacking 방식(위에서 본 층을 쌓는 픽셀 입체)입니다.
`tools/voxels.py` 가 복셀을 쌓아 `sprites/*.png` 슬라이스 띠와 `manifest.json` 을 만들고, `tools/preview.py` 로 견본표를 그립니다.
소방차는 sprite-stacking 스킬로 4방향 그림을 깎아 만든 띠입니다.

## 지도
지도 데이터 © OpenStreetMap contributors (ODbL). 건물 높이는 줄였고 횡단보도·사람·소품은 수업용으로 넣었습니다.

예전 버전: `/classic/`. three.js(MIT)는 `vendor/`에 포함.

## 가현초편 (`/gahyeon/`)
인천가현초 둘레(루원시티) OSM 지도로 만든 같은 게임입니다. 학교가 큰길 위에 오도록 지도를 180도 돌렸습니다.
- `tools/gahyeon_grid.py tools/gahyeon_osm_raw.json data/gahyeon_grid.json` : 지도 격자 다듬기
- `tools/make_gahyeon.py` : 송명편 `main.js` 에서 좌표·이름만 바꿔 `gahyeon/main.js` 생성 (송명편을 고친 뒤 다시 돌리기)
- 새 스프라이트: 가현초 본관·체육관·가현중(실제 발자국), 수차공원 물레방아, 오리 스프링, 루에블리 분수대, 교명 표지석, 아파트 문주, 화단, 승하차 표지판

## 가현 안전상자 (`/diorama/`)
가현초 둘레를 1:150 미니어처 전시 상자(디오라마)로 다시 만든 버전입니다. three.js r170 + 후처리(블룸·틸트시프트).
- 비/맑음/눈, 밤/낮 전환 · 지하주차장 단면 · 층별 분해도(지하/지면/건물/옥상) · 거리 시점
- 상자 곳곳의 아이콘을 누르면 미션 15개(대화·퀴즈 + 상자 안에서 안전한 곳 고르기), 별점·수료증
- 미션 대화는 가현편(`gahyeon/main.js`)에서 옮겨 온 `diorama/talk.js`
