# 안전 탐험대

초등학생용 3D 안전교육 게임입니다. 브라우저에서 바로 실행됩니다(설치 없음, 외부 네트워크 불필요).

- 🚦 횡단보도: 신호를 보고 초록불에 횡단보도로 건너기
- 🔥 화재 대피: 연기 아래로 몸을 낮추고 비상구로 (엘리베이터 금지)
- 🌏 지진 대피: 흔들리면 책상 밑, 멈추면 운동장으로
- 미션마다 OX 퀴즈, 모두 마치면 수료증

조작: 방향키/WASD 이동, Shift 몸 낮추기 · 태블릿은 화면 왼쪽을 끌어 이동, 오른쪽 버튼으로 몸 낮추기.

three.js(MIT)를 `vendor/`에 포함했습니다.
