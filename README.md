# 송명 안전 탐험대

인천송명초 둘레 실제 동네(OpenStreetMap)를 3D로 걸으며 안전 미션 10개를 해결하는 초등 안전교육 게임입니다. 설치 없이 브라우저에서 실행됩니다.

- 🚦 등굣길 스쿨존 횡단보도 · 🚌 버스에서 내린 뒤 · 🛴 킥보드 · 🚗 지하주차장 출입구 · 🛝 놀이터
- 🙅 모르는 사람의 부탁 · 🔥 상가 화재 대피(소방차 출동) · 🌏 학교 지진 대피 · 🚧 공사장 · 🚑 응급 119(구급차 출동)
- 미션마다 대화 선택지 + 직접 행동 + 별점, 10개를 마치면 수료증

## 그림
사람·차·소품은 모두 sprite-stacking 방식(위에서 본 층을 쌓는 픽셀 입체)입니다.
`tools/voxels.py` 가 복셀을 쌓아 `sprites/*.png` 슬라이스 띠와 `manifest.json` 을 만들고, `tools/preview.py` 로 견본표를 그립니다.
소방차는 sprite-stacking 스킬로 4방향 그림을 깎아 만든 띠입니다.
